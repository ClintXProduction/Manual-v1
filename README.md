# CLTX4 Bruce Predatory Manual Website

GitHub Pages-ready product/manual website for the CLTX4 Bruce Predatory CYD full set.

## Deploy
1. Create a GitHub repository.
2. Upload `index.html` and the `manual` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save and open the generated `github.io` address.

Replace package details and seller terms with your actual contents before publishing.
